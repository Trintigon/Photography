# Library

Photographs kept out of the portfolio, held here in case they are wanted later.

Nothing on the site references this folder, so none of it is downloaded by
visitors. It costs page weight nothing; it only sits in the repository.

## What these files are

Re-encoded from the camera originals at **1600px on the long edge**, quality 80,
EXIF stripped. That is the same treatment the photographs in `images/` get, so
anything here can be promoted into the gallery directly — no re-upload needed —
at any tile size except full width, where 1600px is slightly soft on a large
display.

The one exception is `neon-sign.jpg`, which was only ever supplied at 120x160
and is too small to use anywhere on the page.

## Promoting one back

Move the file from `library/` into `images/`, then add a line for it to the
gallery in `index.html` with its group and tile shape. Ask Claude to do it and
name the photograph — the tile shape has to match the aspect ratio or the frame
gets cropped.
